
### Key difference vs Java

| Concept | Java         | JavaScript  |
| ------- | ------------ | ----------- |
| Keys    | `keySet()`   | `keys()`    |
| Values  | `values()`   | `values()`  |
| Entries | `entrySet()` | `entries()` |

---
+-------------+--------------------------+--------------------------+
| Action      | Java                     | JavaScript               |
+-------------+--------------------------+--------------------------+
| Create      | Map m = new              | const m = new Map();     |
|             | LinkedHashMap<>();       |                          |
+-------------+--------------------------+--------------------------+
| Add         | m.put('A',65);           | m.set('A',65);           |
+-------------+--------------------------+--------------------------+
| Get         | m.get('A');              | m.get('A');              |
+-------------+--------------------------+--------------------------+
| Keys        | m.keySet();              | m.keys();                |
+-------------+--------------------------+--------------------------+
| Values      | m.values();              | m.values();              |
+-------------+--------------------------+--------------------------+
| Entries     | m.entrySet();            | m.entries();             |
+-------------+--------------------------+--------------------------+
| Loop keys   | for(k:m.keySet())        | for(const k of m.keys()) |
+-------------+--------------------------+--------------------------+
| Loop entry  | for(e:m.entrySet())      | for(const [k,v] of m)    |
+-------------+--------------------------+--------------------------+
| To array    | new ArrayList(m.keySet())| [...m.keys()]            |
+-------------+--------------------------+--------------------------+
